Blocksize for AI agents

One market-data surface. Six supported agent frameworks.

Use production Blocksize market data as read-only tools in LangChain, LlamaIndex, Vercel AI SDK, OpenAI Agents SDK, GOAT, and Solana Agent Kit. Each implementation preserves timestamps and provenance, uses a stable agent identity, and handles x402 explicitly.

Activation path

  1. Use a stable BLOCKSIZE_AGENT_ID.
  2. Request a live price with the starter allowance.
  3. Inspect the source, timestamp, and provenance in the response.
  4. On HTTP 402, pass the original x402 challenge to the payment flow or top up.
Implementation-ready examples are validated in the Blocksize repository. External framework marketplace publication is tracked separately.
