# Jira Ticket Pack: Market Data Profit OKR

Goal: Increase profit in the market data business by 7,500 EUR / month.

Recommended Jira structure:

- Link all Epics to the Atlassian Goal / Key Result.
- Use each Epic as a deliverable-based project.
- Use child Stories / Tasks for measurable weekly execution.
- Track monthly profit impact in the issue description if no custom field exists.

## Epic 1: Reduce RWA data sourcing cost

Summary: Reduce vendor dependency for RWA market data by replacing or supplementing Tiingo.

Target monthly profit impact: 2,000 EUR / month.

Profit lever: Cost reduction.

Description:
Identify, validate, and integrate online RWA asset data sources that reduce dependency on Tiingo while preserving required quality, reliability, coverage, and licensing safety.

Acceptance criteria:
- Candidate source shortlist completed.
- Coverage, quality, latency, reliability, and licensing reviewed.
- Expected monthly savings calculated.
- Go / no-go decision documented.
- Integration path estimated.

Child tickets:

1. Audit current Tiingo usage and monthly cost baseline
   - Issue type: Task
   - Priority: High
   - Acceptance criteria:
     - Current Tiingo usage mapped by dataset, asset class, endpoint, and consumer.
     - Monthly cost baseline documented.
     - Critical dependencies and replacement constraints listed.

2. Shortlist online RWA data sources
   - Issue type: Task
   - Priority: High
   - Acceptance criteria:
     - At least 3 candidate sources identified.
     - Coverage and data access method documented.
     - Licensing and commercial constraints noted.

3. Validate RWA data quality against existing source
   - Issue type: Story
   - Priority: High
   - Acceptance criteria:
     - Sample comparison completed against current Tiingo output.
     - Missing fields, latency, stale data, and mismatch rates documented.
     - Recommendation produced with confidence level.

4. Prepare RWA source integration plan
   - Issue type: Story
   - Priority: Medium
   - Acceptance criteria:
     - Required engineering work broken down.
     - Risks and rollback path documented.
     - Estimated monthly cost saving confirmed.
